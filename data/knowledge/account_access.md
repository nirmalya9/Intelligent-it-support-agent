# Account access and authentication troubleshooting

Symptoms: account locked, password problems, MFA failures, or permission denied.

1. Verify the username and exact application being accessed.
2. Use the organization's approved password reset process. Never ask a user to send a password.
3. For locked accounts, follow official identity verification and unlock procedures.
4. For MFA problems, use only the approved recovery process. Never request an MFA code.
5. For permission errors, record the resource name and business justification, then route the request to the resource owner.
6. Access grants must be approved by an authorized owner.
Escalate suspected account compromise immediately through the official security process.
