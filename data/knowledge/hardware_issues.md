# Laptop and peripheral troubleshooting

Symptoms: overheating, display problems, keyboard failures, battery issues, or laptop will not start.

1. Record device model, operating system, symptoms, and when the issue started.
2. Save work and restart only if safe and appropriate.
3. For display issues, check cable connections and monitor input selection.
4. If a device is unusually hot, smells burnt, has a swollen battery, or shows physical damage, stop using it and contact hardware support. Do not open the device.
5. Attach a description of error lights or messages and escalate hardware faults to approved support.
