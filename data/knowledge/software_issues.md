# Desktop software troubleshooting

Symptoms: application crashes, installation failures, browser errors, or update problems.

1. Record application name, version, operating system, and exact error.
2. Restart the application and check whether a supported update is available.
3. Confirm sufficient disk space and whether the issue affects one application or several.
4. Use only approved software installation and update procedures.
5. Do not disable endpoint protection or bypass organization policy to install software.
6. If the issue persists, provide relevant logs with secrets and personal information removed.
